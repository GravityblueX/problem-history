# Sources and Evidence Levels

这份 pilot 必须区分 **当时材料**、**后来的官方史叙述** 与 **本仓库的研究者重建**。三者都可以使用，但不能赋予同样的证据权重。

## Evidence level A — 当时规范性/行动者材料

### 1949：《中国人民政治协商会议共同纲领》

用途：证明国家层面对文化教育、科学、文艺、人才培养和旧知识分子教育的明确制度表述。

- https://hljzx.gov.cn/contents/73/7476.html

关键可证事项：

- 文化教育被纳入国家政策；
- “培养国家建设人才”是明确目标；
- 自然科学与工业、农业、国防建设建立制度性关联；
- 文学艺术被置于“为人民服务”的政策框架；
- 青年知识分子和旧知识分子的政治教育被直接写入国家建设需要。

不能单独证明：社会中的知识分子都接受了这一问题框架。

### 1949：第一次中华全国文学艺术工作者代表大会

- 总资料：https://www.cflac.org.cn/wdh/cflac_wdh-1th.html
- 周恩来政治报告：https://www.cflac.org.cn/wdh/cflac_wdh-1th_Article-06.html
- 周扬报告节选：https://www.cflac.org.cn/ysb/2009-07/15/content_17109906.htm

用途：证明“全国会师 / 全国组织 / 新社会中文艺工作的位置”在建国前夕已经成为行动者明确问题。

特别重要：这可以防止把所有变化机械归因于 1949-10-01 当天。

### 1951：周恩来《关于知识分子的改造问题》及同时期政策行动

目前使用可核验的官方大事记和政策史页面定位文本与核心 formulation：

- https://cpc.people.com.cn/GB/64162/64164/4416026.html
- https://cpc.people.com.cn/GB/64107/65708/65722/4444952.html
- https://www.counsellor.gov.cn/2021-06/09/c_1211193508.htm

用途：证明“人民立场 / 工人阶级立场 / 思想改造”进入问题中心。

限制：当前 pilot 尚未取得一份稳定、可逐段引用的 1951 报告全文版本。后续正式研究应补充《周恩来选集》等可靠文本版本并记录页码。

### 1956：知识分子问题会议

- 中国共产党大事记：https://cpc.people.com.cn/GB/64162/64164/4416035.html
- 会议政策史：https://cpc.people.com.cn/GB/64107/65708/65722/4444834.html
- 九三学社档案介绍：https://www.93.gov.cn/lshm-sszl/205990.html

用途：证明 1956 年行动者明确重估知识分子的社会位置，并把科学技术、人才使用和世界先进水平纳入新的问题结构。

### 1956：郭沫若《在社会主义革命高潮中知识分子的使命》

- https://www.cppcc.gov.cn/2011/10/09/ARTI1318130440612682.shtml

用途：非常强的 actor-level 辅助材料。它明确列举：知识分子数量、业务能力、政治觉悟、使用、待遇、国家建设需要等变量。

它尤其支持 `problem_responsibility` 的变化：问题不只在知识分子个人，也可能在使用知识分子的政府部门。

## Evidence level B — 后来官方历史叙述

这类材料可以用于：

- 定位事件时间；
- 找文献线索；
- 了解后来形成的政策史解释；
- 研究“后人如何重述这个问题”。

但不能自动替代当时材料。

例如：

- 人民网/党史网关于知识分子政策的回顾；
- 国务院参事室统战史话；
- 新中国文化建设周年回顾文章。

### 特别警告

后来的叙述常把 1949—1956 写成一个已有结论的政策发展过程。问题史必须防止把这种 retrospective coherence 倒灌给当时行动者。

应单独保存：

```yaml
claim_origin: retrospective_official_history
```

而不是标成：

```yaml
claim_origin: contemporary_actor
```

## Evidence level C — 本仓库的重建判断

以下不是历史文本中的原话，而是研究者目前的分析标签：

- `problem-producing transition`；
- `transformed_successor`；
- `knowledge-state-building`；
- `intellectual-political-remolding`；
- `intellectual-scientific-capacity`；
- “1951 的部分成功破坏了旧问题继续占据中心的条件”。

这些都必须标为：

```yaml
claim_origin: researcher_reconstruction
status: defeasible
```

如果后续加入高校教师日记、科学家通信、文艺工作者私人文章后发现存在完全不同的问题框架，应修改这些标签，而不是强迫新材料进入既有结构。

## Missing evidence / 下一轮材料缺口

### 1. 知识分子自己的非官方材料

目前材料过度集中于国家和全国性组织。

需要补：

- 大学教师日记、书信、学习笔记；
- 科学家关于科研条件和国家工作的通信；
- 作家在 1949—1952 年对身份变化的私人或公开反思；
- 海外归国知识分子对“回国 / 建设 / 专业 / 政治”的自我表述。

### 2. 机构内部材料

例如：

- 大学接管与院系调整档案；
- 中国科学院早期机构文件；
- 科研规划讨论材料；
- 文联、作协等组织的会议记录。

这些可以检验“国家建设能力”是否真的在日常制度中成为问题，而不只是纲领性语言。

### 3. 竞争问题框架

必须寻找不接受主流 formulation 的材料：

- 有人是否认为专业自主比政治改造更紧迫；
- 有人是否认为“知识分子”这个分类本身过于粗糙；
- 不同学科对国家建设的理解是否冲突；
- 文艺、自然科学、教育中的“为人民服务”是否其实指向不同 problem structures。

如果找不到竞争框架，这个 pilot 只能算政策问题史，不能升级成整个“知识分子问题史”。
